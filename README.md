# Modern Interactive Portfolio Template

Web portfolio modern, interaktif, dan customizable menggunakan React + Vite.

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka browser ke:

```bash
http://localhost:5173
```

## Build Production

```bash
npm run build
npm run preview
```

## File Utama

- `src/main.jsx` — struktur komponen, data portfolio, project, skills, timeline, customizer.
- `src/styles.css` — desain dark cyberpunk, responsive layout, modal, toast, drawer.

## Fitur

- SPA one-page portfolio.
- Sticky navbar hide/show saat scroll.
- Mobile hamburger menu.
- Hero dengan typing effect.
- Code terminal visual.
- About, skills, project filter, project modal.
- Timeline pengalaman.
- Contact 3 kolom.
- Floating UI customizer.
- Toast notification.
